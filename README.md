# Git-Ghost
CLI-утилита для скрытия секретных текстовых сообщений внутри файлов Markdown (например, README.md) с помощью методов цифровой стеганографии. Позволяет незаметно «растворять» приватную информацию прямо внутри публичных репозиториев на GitHub без нарушения исходного форматирования, а также мгновенно извлекать данные по прямой ссылке.
